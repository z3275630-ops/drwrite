# Drwrite 界面精修方案

日期：2026-10-28。承接《修改方案-2026-10-27-Kimi全量适用项.md》，不减少已选的 18 项功能。用户已选择“精修浮层：保留正文背景，突出主要操作，次要设置展开查看”。本文件先于本轮视觉精修代码落盘。

## 目标与保留项

延续现有暖纸色、棕色强调、柔和边线和小说正文排版。左管全书、右管当前章或 AI；首次两侧展开；专注退出入口保持可见。新增工具要融入同一张写作桌，而不是一组系统设置窗口。

本轮已经发现：任务与导出窗呈现了过多同级表单；部分新增输入和选择框未沿用统一样式；对话历史说明被挤成竖列；长任务的主要按钮会随内容滚走；建卡原始 JSON 比人物建议更抢眼。以上均纳入修正。

## 参考与复用

- 直接沿用项目颜色变量、按钮和既有阅读排版，不引入另一套视觉主题。
- 沿用 Radix Dialog 管理浮层、焦点与背景隔离。选择框使用同体系 Radix Select，参考其官方源码的键盘、定位、滚动与焦点实现，适配项目样式；不自行编写下拉交互引擎。已核对 npm 2.4.1、MIT、React 19 兼容，实际版本以锁文件为准。
- 复用现有 HTML 输入、复选和 details 的语义与键盘行为，只统一外观；不把按钮伪装成不能键盘操作的开关。

参考：https://www.radix-ui.com/primitives/docs/components/select ，https://github.com/radix-ui/primitives/tree/main/packages/react/select 。新增依赖须补充许可证。

## 统一规范

1. 浮层保留正文背景，但以浅遮罩、明确标题、简短用途说明区分层次。标题栏与主要操作区在滚动时保持可达，内容本身滚动，避免整个标题消失。
2. 表单控件统一纸色底、细边、圆角和棕色聚焦态；常规高度约 38–40 px，紧凑右栏约 30–32 px。使用统一下拉菜单，不暴露一排未修饰的系统选择框。深色模式复用现有颜色变量。
3. 主要按钮每个阶段只有一个：准备任务／开始剩余批次／确认采纳／导出／创建副本。取消、返回、查看详情使用次级或文字按钮。危险操作有独立语义，不与常用动作并列争抢。
4. 上下文预算、文件名模板、完整请求、原始回复放到明确标注的展开区；来源开关和本次范围保持可见。不能为了简洁隐藏保存失败、真实批次数、目标路径和覆盖提示。
5. 结果优先展示可读卡片、摘要、正文对照。JSON 与内部模型端点只在确有核对需要的详情中展示。状态使用文字与形状配合，不能只靠颜色。
6. 状态说明使用分组条或提示卡，不堆成多段技术警告。对话的会话选择、来源和输入区分别排布；说明文字占完整宽度，不能把正文列表挤没。

## 具体改动

| 界面 | 精修内容 |
|---|---|
| AI 任务 | 首屏优先类型、范围和章数；预算与资料选项放进“上下文设置”；准备后显示批次摘要与开始操作；已保存任务、结果与采纳分区；原始回复默认折叠。 |
| 导出 | 首屏优先范围、格式、目标；正文内容开关与分章命名归入“内容与命名”；勾章区有独立滚动；选定章数和最终导出按钮始终易找。 |
| 完整副本 | 使用来源摘要、目标位置和结果卡；选择目录与路径组成一行；实际进度、失败、最终路径保持清楚。 |
| 上下文确认 | 顶部显示本次用量摘要，预算可调整但不过分抢眼；来源每项一行，有纳入量和开关；片段与完整请求折叠。 |
| 提案 | 版本与用量归为摘要条，原文／产出保持主体；反馈调整为次级区域，差异有明确新增／删除标签。 |
| 右栏与结构工具 | 输入、选择、空状态、人物提示和时间字段统一设计；右栏不采用巨大表单；保持草稿、切章、撤销的原有保护。 |

## 验收标准

- 1280×800 和最小窗口下，浮层不溢出屏幕；主要按钮可达，长列表在自己的区域滚动。
- 深浅两种主题的输入、下拉、选中与禁用态均可辨认；不出现白色系统选择框、竖排说明或被截掉的核心操作。
- Tab、上下键、回车、Esc 可操作；下拉中的 Esc 只关闭下拉，不能顺带丢掉整份表单；中文组合输入不误提交或关闭。
- 折叠前后，所选范围、草稿、任务检查点和导出内容一致；任何错误提示和重试入口不能因精简消失。
- 用官方 Computer Use 实际打开每类浮层核对，继续使用独立标识的验收版和合成书库。构建、逻辑测试通过不替代视觉验收。
- 本轮完成后再打正式 0.8.0 安装包，正常覆盖安装，并核对实际运行版本。尚未实测的缩放或屏幕阅读器场景如实记录。

### 实施说明

- 控件复用 Radix 的焦点、方向键与菜单定位；项目自行适配颜色、间距、信息分组和固定操作区，没有新增另一套交互引擎。
- 标准系统目录选择器继续由 Windows 提供，应用内的任务、导出、副本和来源确认界面采用统一浮层。
- 副本和导出成功后主按钮改为“完成”；展示路径去掉 Windows 内部长路径前缀，原始路径继续用于打开文件位置。
- 正式发行构建已核对不包含性能采集标记；性能原始数据只来自明确启用的独立 QA 构建。

正式 0.8.0 已于 2026-10-28 保留数据覆盖安装；书架版本、正常环境安装登记和两个快捷方式已核对。详见主修改方案的正式交付记录。
