## 技术底座

Tauri 2 + React + TypeScript + Vite + Tailwind + shadcn/ui + Tiptap。
存储：每本书一个文件夹（章节 = Tiptap JSON，实体 = JSON，SQLite 仅索引/全文检索），git 友好。
AI：BYOK 多供应商（OpenAI 兼容协议 + Ollama），无服务端。

## 工程原则（从织境拆解继承，写代码时必须遵守）

1. 数据模型先行，派生分析不落库
2. 防假保存：任何"看起来在"的状态必须落盘
3. 手写内容神圣：AI 只填空，不碰用户写过的字段
4. 引用存稳定 ID，改名不断链；识别≠关联（淡提示+显式确认）
5. 全应用统一撤销栈（正文+结构+资料+AI 同一时间线）
6. 所有交互元素给 aria-label
7. 空状态与错误文案说人话
